# Secretly a Witch — Instagram content plan (v1, 2026-08-17)

The working plan behind the chat `secretly-witch-instagram-content`. Sophie
asked for two content tracks for the @secretlyawitch Instagram, delivered as a
swipeable deck Compare page she reviews with ♥/✕ and per-card notes. This doc
is the source the deck was built from; her verdicts live on the page
(`GET /api/chatfeed/verdict?chat=secretly-witch-instagram-content`).

## The two tracks (her framing)

1. **Aesthetic posts** — by-eye visual posts. Mockups generated with
   gpt-image-2 (medium, 1024x1536 for feed portrait, 1024x1024 for square
   memes) so she can judge the look, not just read a description.
2. **Informational posts, half earnest / half funny** — earnest spell how-tos
   (carousels/reels, written in the witch-copy house voice), and relatable /
   fairly edgy witch memes ("I have weird taste" — edgy is welcome).

## The shared mockup style prompt (v1, by Claude)

> Moody editorial photograph for a witchcraft brand's Instagram feed, dark
> ink-black and deep plum palette with warm candlelight gold accents,
> chiaroscuro lighting, shallow depth of field, fine film grain, shot on
> medium format film.

Meme variant swaps the first clause for "Moody photograph meme post for a
witchcraft Instagram account" and appends the overlay text. The palette
deliberately matches the witch app's own theme (ink/plum + gold + moonlight)
so the feed and the app read as one brand.

## Rules that bound this work

- All reader-facing copy follows the `witch-copy` skill (no Claude-isms,
  aspirational not consoling, researched specifics). Memes are humor but the
  banned-phrasing list still applies.
- Every mockup is filed per the `deliver-images` ritual: labeled, MODEL ·
  QUALITY caption (`gpt-image-2 · medium`), exact prompt split style/content,
  posted to the iOS My Creations gallery with true generation timestamps.
- Iteration model: she swipes and leaves notes on the deck; the next version
  is a NEW page (new-version rule), built from her verdicts + notes.
