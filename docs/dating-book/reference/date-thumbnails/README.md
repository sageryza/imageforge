# Date thumbnails

One small thumbnail per date, cropped from the `LEGAL SIZE DATE POSTER`
(`../date-watercolors/_ALL-DATES-poster-roster.png`). `date-01.png` … `date-40.png`
are numbered in the poster's reading order (5 across, 8 down), matching the
numbered reference image. Low-res (~160 px) — intended for datebook thumbnail
use. Full-res versions exist for 18 of these in `../date-watercolors/`.
