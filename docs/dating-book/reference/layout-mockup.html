Layout Notes
This is a two-page spread for a medium-length date. Shorter dates might be a single page (portrait + text + timeline, no separate chart page). Longer dates could extend to three pages with more detail drawings or a longer timeline. The watercolor wash color in the header bar would be unique per date. All placeholder boxes would contain your watercolor + ink illustrations.
