## The rules, distilled

- **Two parts:** making the images, and adding the voiceover.
- **Voiceover:** use the NDE precise-cutting alignment
  (`docs/nde-precise-cutting.md`) so the actual words and their timestamps
  line up — otherwise it gets wonky.
- **Images:** the **pastel variant V2** style from the Test Station.
  Aspect ratio is **portrait 2:3** (not square), so it works on a phone.
- **The concept formula** (per concept, not an exact science):
  1. First image: what is LITERALLY happening, realistic.
  2. Next image: an emotional / metaphorical / dream-sequence take on the
     same moment — keeping continuity (same people, same conversation),
     only the context transformed. Example: a realistic car ride, then the
     same car slowly drifting into outer space with the same people still
     talking inside it.
  3. Animate BETWEEN the two panels — the animation is what makes the leap
     feel commonplace, like the two images naturally belong next to each
     other. (She marks this animation step "the next step, don't worry
     about it yet.")
- **The goal:** force the viewer to imagine the concept being described —
  think first about how someone would model the concept in their mind.
