One album per crystal, several shots of each — that's one Etsy listing per album. Drop them here and they keep that grouping, so a chat can pull them back out to price, write, and build the pick-your-own grids.

Add photos

Every photo in one upload is treated as the SAME stone and shares its number. Leave the name blank and each photo becomes its own crystal.
Each folder inside the ZIP becomes one crystal, named after the folder. This is the fast path: do it once and every album lands grouped and named.
How to get albums off the phone into a ZIP
  1. Files app → make one folder, e.g. Crystals.
  2. Photos → open an album → Select → Select All → Share → Save to Files.
  3. Pick Crystals → New Folder → name it the crystal → Save.
  4. Repeat for each album (this is the only repetitive bit).
  5. Files → long-press the Crystals folder → Compress → upload that .zip here.
